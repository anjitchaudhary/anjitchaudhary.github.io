# Anjit Chaudhary — Enhanced 3D Portfolio

Responsive portfolio built with plain HTML + CSS.

## Included
- CSS-only 3D portrait/orbits
- Animated ambient background, stars, grid floor and entrance loader
- Hover micro-interactions
- Responsive mobile/tablet/desktop layout
- Social/contact icons without external icon libraries
- Projects: ChatLoom, Portable USB AI, Quanta AI, NexVibe, Aloha Browser, Music Player, Attendance App and Small Builds
- Supplied portrait in `assets/anjit-portrait.jpg`

## Run
Open `index.html` in a modern browser.

No JavaScript framework or backend is required.
